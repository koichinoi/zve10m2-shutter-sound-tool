# ZV-E10M2 1.02 创意外观 FL2／FL3

[下载 FL2／FL3 合并数据包](FL2-FL3.json)。每套包含照片、视频所用的色调曲线，以及色彩表和参数映射的差分。

| 外观 | 使用的原机入口 |
| --- | --- |
| FL2 | IN |
| FL3 | SH |

两套数据来自已完成写入并通过冷启动回读的 ZV-E10M2 1.02 实验。拍摄的 ARW 中也核对了曲线和色彩参数。原厂机型的 JPEG 成像等效性未验证。

## 在软件里生成

打开 v0.3.0 或更新版本，点击右上角「FL2／FL3 外观」。选择原始备份目录和输出位置，默认生成两套。输出位置下会新建 `ZVE10M2-FL2-FL3` 目录。下拉菜单也可单选 FL2 或 FL3。

## 导入相机

v0.3.1 提供「导入两套到相机」。这一流程使用内置的 FL2／FL3 数据与匹配的本地研究工具，分别替换 IN 和 SH 的成像数据。需要从兼容的原始状态开始，已安装的相机会在核对通过后提示跳过。

1. 确认相机电量超过 50%，以 USB 海量存储器连接电脑。
2. 在主窗口勾选电量确认，再打开「FL2／FL3 外观」。
3. 点击「导入两套到相机」，确认操作。保持供电和 USB 连接，等待备份、写入和回读完成。
4. 成功后拔线、关机，等读写灯熄灭，取出电池约一分钟再开机，进入创意外观分别拍照核对。

导入前须具备与工具匹配的 FL2／FL3 本地研究文件，包括 `work/fl23_research` 下的候选报告、原生写入和恢复程序、设置协议模块及相应验证记录。程序会核对相机的色彩程序、当前和已保存的色彩设置、快门音与相关文件。备份和报告位于软件的 `operations` 目录。遇到中断或回读不符时，保留 `pending.json` 和报告供核对。

新版按钮通过离线事务模拟。此前的相机写入和冷启动回读来自专用研究流程。导入只处理两套成像数据，菜单名称和图标由相机现有资源决定。

## 命令行生成

需要从自己的匹配研究备份中准备三个原始文件，并放入同一个目录：

- `cpapp-b.bin`
- `unit-02a40001.bin`
- `unit-02a4000d.bin`

原始文件长度和 SHA-256 记录在合并数据包 里。脚本先核对所有输入，再生成并校验输出副本。

```powershell
python filters/apply_offline.py D:/camera-original D:/fl23-output
```

若只需要其中一套，改用一个新的输出目录，追加 `--look FL2` 或 `--look FL3`。分别生成的结果属于各自的原始基线，不能在已修改的输出上再叠加另一套。两套同时应用用默认命令。

命令行脚本只生成离线副本。相机导入使用上面的软件入口和匹配的本地研究环境。JSON 中的偏移仅适用于所列基线。菜单文字改名是单独的改动，不在这些成像数据里。原始相机程序和完整备份保存在本地研究环境。
