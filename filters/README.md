# ZV-E10M2 1.02 创意外观 FL2／FL3

[下载 FL2／FL3 合并数据包](FL2-FL3.json)。每套包含照片、视频所用的色调曲线，以及色彩表和参数映射的差分。

| 外观 | 使用的原机入口 |
| --- | --- |
| FL2 | IN |
| FL3 | SH |

两套数据来自已完成写入并通过冷启动回读的 ZV-E10M2 1.02 实验。拍摄的 ARW 中也核对了曲线和色彩参数。原厂机型的 JPEG 成像等效性未验证。

## 离线生成

需要从自己的匹配研究备份中准备三个原始文件，并放入同一个目录：

- `cpapp-b.bin`
- `unit-02a40001.bin`
- `unit-02a4000d.bin`

原始文件长度和 SHA-256 记录在合并数据包 里。脚本先核对所有输入，再生成并校验输出副本。

```powershell
python filters/apply_offline.py D:/camera-original D:/fl23-output
```

若只需要其中一套，改用一个新的输出目录，追加 `--look FL2` 或 `--look FL3`。分别生成的结果属于各自的原始基线，不能在已修改的输出上再叠加另一套。两套同时应用用默认命令。

这些文件用于离线研究。相机安装仍需要与固件、当前设置和回滚方案匹配的专用流程。JSON 中的偏移仅适用于所列基线。菜单文字改名是单独的改动，不在这些成像数据里。原始相机程序和完整备份保存在本地研究环境。
